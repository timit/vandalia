the 8027's second pre-installed 15A branch (previously wired toward BAOMAIN 2 - oven/cooktop AC source switch for the velit leg) is now spare, freed up by the 2026-09-21 velit redesign below. it's a candidate for the water heater circuit, still TBD in the load budget — not assigned yet.

quantities: 2/0 lugs with 3/8" holes x6, 2/0 with M8 holes x4. measure every run and add about 20% slack.

XS terminals (IN, GND, OUT) are screw terminals — no lug needed, bare stranded wire or a bootlace ferrule. torque: 4 AWG 50 in-lb (5.6 Nm), 6-10 AWG 40 in-lb (4.5 Nm), 8-12 AWG 25 in-lb (2.8 Nm). the screwdriver blade must be 1.2mm thick with minimal taper over the first 2mm — a common 6.3mm bit with a 1mm blade will cam out. max cable size the terminal accepts is 4 AWG.

SOK terminal (lug) torque is 9-11 N·m (about 80-97 in-lb) per its own manual — higher than the egis busbar torque (120-140 in-lb / 13.6-15.8 N·m) listed below, so don't reuse the same torque setting for both. max 150A per SOK terminal/cable pair; if that's ever a binding limit, the fix is a second cable pair, not a bigger single lug.

battery selectors (aramox 300A, off-1-2): M10 studs, confirmed via photos of the actual units plus multiple independent listings of the same generic OEM switch under other brand names (spartan power, seaflo) — this corrects an earlier "5/16" assumption, which is too small to fit. terminals are labeled "OUTPUT" (common), "1", "2". printed rating: 300A continuous, 500A for 5 min, 900A for 30 sec. this build uses both owned units: **selector 1** shares the van feed between the DJI charger (position 1) and the orion XS (position 2) (existing design, phase 3). **selector 2** (2026-09-21) chooses the velit's DC source — position 1 is the DJI-fed meanwell's output, position 2 is a direct tap off the 24V bus. both follow the position-1-is-DJI convention below. selector 2 only switches the positive leg; that's sufficient (not unsafe) specifically because the meanwell is a galvanically isolated AC-DC supply (3kVAC input-output isolation, per its datasheet) — permanently bonding its DC output negative to the same negative bar the 24V bus already uses doesn't cross-connect the DJI and victron systems, since the isolation barrier inside the meanwell blocks that path. a single-pole switch would not be safe here if the two sources' negatives weren't already tied to a common reference this way. switch only with the velit powered off — these are mechanical disconnect switches, not rated for breaking load current, and this build has no other DC-under-load switching anywhere else to compare against.

cerbo GX MK2 CAN wiring for the SOK: this unit has 2 fully configurable VE.Can ports (labeled VE.Can 1 and VE.Can 2 — not a fixed "BMS-Can" port like the original Cerbo GX). dedicate one port to the SOK, terminate the cerbo end with one of the 2 included VE.Can terminators, and follow the SOK's own instructions for termination on the battery side. set the port's profile (Settings → Connectivity → VE.Can port → CAN-bus Profile) to **BMS-Can (500kbit/s)**. SOK itself is not on victron's official compatibility list (checked directly at victronenergy.com/live/battery_compatibility:start — 28 named brands, SOK not among them), but its BMS is reported to use the Pylontech CAN protocol and gets auto-detected as a "Pylontech" device once connected (multiple independent DIY solar forum reports). that auto-detection in the cerbo's device list is the real confirmation to look for — not the name "SOK" appearing anywhere. community-sourced, not a victron guarantee.

## switch position convention

**position 1 is always the DJI leg; position 2 is always the victron leg** — on every switch that splits between the two systems (BAOMAIN 1 - shore AC destination switch, BAOMAIN 3 - fridge/receptacle AC source switch, BAOMAIN 2 - oven/cooktop AC source switch, battery selector 1, battery selector 2). set 2026-09-21 for the first four of those; BAOMAIN 2 joined this list on 2026-10-02 when the kitchen redesign brought it back into active use as a source-selector, following the same convention. to match the switches' physical layout: the DJI system is mounted driver side (left), the victron gear is passenger side (right), so turning a switch left (position 1) selects DJI and turning it right (position 2) selects victron — the throw direction matches the side of the van each system is actually on.

## BAOMAIN transfer-switch terminal wiring

the real BAOMAIN operating instructions (reference/baomain-operating-intructions.pdf) give a truth table (position 1 closes terminals 1-2 and 5-6; position 2 closes 3-4 and 7-8; position 0 opens all) but don't spell out the transfer-switch application itself. the jumper-based pattern below (originally found via RV/van build community sources) is exactly consistent with that official truth table, which is a real step up from "community-sourced" — but BAOMAIN still hasn't confirmed this specific application in writing. verify with a continuity meter before energizing, per the install order below.

the trick: jumper two terminals together to turn the switch's two independent contact pairs into one proper double-throw. **terminal 2 to terminal 4** (jumper) becomes the common hot; **terminal 6 to terminal 8** (jumper) becomes the common neutral. terminal 1/5 is the "position 1" leg; terminal 3/7 is the "position 2" leg. ground never goes through the switch — bond all grounds together directly.

it doesn't matter electrically which side is "source" and which is "load" (it's a passive mechanical switch), so:

- **BAOMAIN 1 - shore AC destination switch** (one source, two destinations): common (2+4, 6+8) = 8077 output, hot/neutral. terminal 1/5 = 3131 box / DJI branch, hot/neutral (pos 1). terminal 3/7 = multiplus AC-in, hot/neutral (pos 2).
- **BAOMAIN 3 - fridge/receptacle AC source switch** (two sources, one destination, 2026-10-02 kitchen redesign): terminal 1/5 = DJI AC output port, hot/neutral (pos 1). terminal 3/7 = 8027's existing 15A branch, hot/neutral (pos 2). common (2+4, 6+8) = the 15A fridge+USB circuit.
- **BAOMAIN 2 - oven/cooktop AC source switch** (two sources, one destination, 2026-10-02 kitchen redesign — no longer spare): terminal 1/5 = DJI AC output port, hot/neutral (pos 1). terminal 3/7 = 8027's new 20A breaker, hot/neutral (pos 2). common (2+4, 6+8) = feeds BAOMAIN 4 - oven/cooktop AC destination switch's common, not an appliance directly.
- **BAOMAIN 4 - oven/cooktop AC destination switch** (new, 2026-10-02 — one source, two destinations, same topology as BAOMAIN 1 - shore AC destination switch but switching loads instead of sources): common (2+4, 6+8) = BAOMAIN 2 - oven/cooktop AC source switch's common output, hot/neutral. terminal 1/5 = oven's receptacle (pos 1). terminal 3/7 = cooktop, hardwired direct — no receptacle, confirmed 2026-10-02 (pos 2). this switch's job is a mechanical interlock — oven and cooktop can never both be live at once, which is what keeps their combined 3550W off every power source in this build (see limits below). because it selects between two *loads* rather than two *sources*, the position-1-is-DJI convention doesn't apply here; which appliance sits on which leg is arbitrary.

each switch needs two short jumper wires (2-to-4, 6-to-8) not currently on the parts list — match each switch's own circuit gauge: **10 AWG** for BAOMAIN 1 - shore AC destination switch's 30A run, **14 AWG** for BAOMAIN 3 - fridge/receptacle AC source switch's 15A circuit, **12 AWG** for BAOMAIN 2 - oven/cooktop AC source switch and BAOMAIN 4 - oven/cooktop AC destination switch's shared 20A circuit (BAOMAIN 2 - oven/cooktop AC source switch's common carries whichever source is selected into the 20A branch; BAOMAIN 4 - oven/cooktop AC destination switch's common carries that same 20A branch, so both match the circuit's gauge, not the gauge of either individual leg).

terminal is M4 screw, per the real manual: accepts 2.5-6.0mm² wire (about 14-10 AWG), torque 1.2 N·m. 10 AWG (used on BAOMAIN 1 - shore AC destination switch) is at the top of that range.

## install order

everything off, SOK off, no fuses installed. this is the actual sequence used starting with the 2026-09-20 install session: AC input first, then the DC backbone (so shore can charge the SOK), then the alternator branch. cerbo/DVCC and the DJI AC branch aren't part of this pass — they come later.

**phase 1 — AC input to the multiplus**

1. shore power disconnected the entire time. mount the inlet, 8077, BAOMAIN 1 - shore AC destination switch, and multiplus.
2. wire inlet to 8077 to BAOMAIN 1 - shore AC destination switch, **10 AWG 3-conductor** throughout, 10ft max on the inlet-to-8077 leg (see measurements.md). land the 8077 output on BAOMAIN 1 - shore AC destination switch's common terminals — jumper terminal 2 to terminal 4 and terminal 6 to terminal 8, **10 AWG jumper wire** (matches BAOMAIN 1 - shore AC destination switch's own 30A circuit gauge). install these jumpers now even though only one leg is used today, so this switch never needs rewiring when the DJI branch is added later.
3. terminal 3/7 to multiplus AC-in, **10 AWG 3-conductor** (position 2 — see the switch position convention above: position 1 is reserved for the DJI leg, wired later). leave terminal 1/5 unconnected (DJI leg, later).
4. continuity check before anything is live: no continuity hot-neutral, hot-neutral-ground anywhere in what was just wired; confirm position 2 connects it and position 0 opens it.
5. do not plug in shore power yet — hold here until phase 2 is done. do not wire AC-out-1, the 8027, or any outlets yet (see the neutral-ground note below).

**phase 2 — DC backbone (battery hookup, so shore can charge it)**

6. cut, crimp, pull-test, and heat-shrink the 2/0 cables.
7. wire the negative side first: SOK- to negative bar to multiplus- (**2/0** both legs), the multiplus's separate exterior grounding point to the same bar (**10 AWG minimum**, terminal location on the unit: verify), then the single chassis bond off the negative bar (**2 AWG**, to the factory stud — see below). this is the system's only ground reference — it goes in before anything else.
8. wire the positive side: SOK+ to class T fuse block (fuse not inserted yet) to positive bar to multiplus+, **2/0** throughout.
9. continuity check: no continuity between the + and - bars. torque every stud (egis busbar studs 120-140 in-lb; SOK terminals 9-11 N·m — different torque, don't reuse the setting).
10. install the class T fuse last. turn on the SOK. a small spark on connection is normal.
11. before plugging in shore power: connect to the multiplus over victronconnect and set the battery profile to lithium, absorption at or below 27.6V (not the factory default gel/AGM profile). there's no cerbo/DVCC in this partial install to do this automatically — skipping this step means the multiplus starts charging the SOK on the wrong profile the moment shore power is connected.
12. now plug in shore power. once AC is live: verify with a multimeter — 120V hot-to-neutral, 120V hot-to-ground, 0V neutral-to-ground — and confirm the reverse-polarity LED is off before turning on any branch circuit (per blue sea's own testing steps; only meaningful at the 8027 once that panel is wired, later).

still don't wire AC-out-1, the 8027, or energize any outlet yet. the system's only neutral-ground bond happens inside the multiplus, via its ground relay, which needs DC power to engage — without a battery connected there's no ground reference anywhere in the AC system.

**phase 3 — alternator: van feed to battery selector 1 to orion XS to battery**

13. pull the AEP fuse on the van feed (or disconnect the starter battery terminal) before touching any of this — that wire is live off the starter battery. even with the fuse pulled, the short segment between the battery and the fuse holder itself stays live.
14. mount battery selector 1 (aramox) and the orion XS.
15. land the van feed (the existing 6 AWG wire) on selector 1's "OUTPUT" terminal, M10 stud. confirm where along that existing wire to splice in the selector, and whether it reaches (still open, see verify.md — the separate selector-1-to-XS-input reach question is resolved: confirmed long enough as-is, 2026-10-03).
16. selector 1 terminal "2" to XS IN, 6 AWG (position 2 — victron leg, per the switch position convention above; matches the shared feed and XS output/GND — this run is under the bed, same short-run reasoning). no jumper needed here — the aramox switch already has a true common plus two legs, unlike BAOMAIN.
17. leave terminal "1" unconnected for now (DJI charger leg, position 1, later) — no rework risk, since there's no jumper to move.
18. XS OUT to 6 AWG to 60A ANL (5123) to the positive bar built in phase 2.
19. XS GND to 6 AWG to the negative bar (matches XS output — same current, same short run under the bed).
20. continuity check with selector 1 in OFF: confirm position 2 connects OUTPUT to "2" and nothing else, before reinserting the fuse.
21. reinsert the AEP fuse. switch selector 1 to position 2 (victron/XS leg).
22. configure the XS over victronconnect: lithium profile, absorption at or below 27.6V, input current limit about 60A, engine-running detection on.

AC wiring is the dangerous part of this build — have it inspected before energizing anything past the inlet, especially the BAOMAIN switches, since BAOMAIN's own manual doesn't spell out the transfer-switch application even though the terminal wiring here matches its truth table.

**phase 4 — multiplus AC-out to the 8027, kitchen (BAOMAIN 3 - fridge/receptacle AC source switch, BAOMAIN 2 - oven/cooktop AC source switch, BAOMAIN 4 - oven/cooktop AC destination switch), the velit (battery selector 2, direct DC), and the 5026 12V bus**

shore power (or at least this branch) off while wiring. this phase wires only the victron-sourced legs (position 2) of BAOMAIN 3 - fridge/receptacle AC source switch and BAOMAIN 2 - oven/cooktop AC source switch, plus BAOMAIN 4 - oven/cooktop AC destination switch in full (it has no DJI/victron leg at all — see the switch-position-convention note above). the DJI AC-output-port taps (position 1 on BAOMAIN 3 - fridge/receptacle AC source switch and BAOMAIN 2 - oven/cooktop AC source switch) are deferred like every other DJI branch in this build. pull the AEP-style caution for anything touching the 24V bus, same as phase 2 and 3.

the kitchen redesign (2026-10-02): real nameplate watts are now in (oven 1750W, cooktop 1800W with its own 20A-minimum breaker requirement, fridge 35-45W assumed on its AC input — see README's load budget and the limits section below for the full reasoning). two circuits, not one shared branch:

23. multiplus AC-out-1 to the 8027, **10 AWG 3-conductor**, landing on the 8027's own 30A main.
24. 8027's existing 15A branch to BAOMAIN 3 - fridge/receptacle AC source switch terminal 3/7 (fridge+USB circuit, position 2), **14 AWG**. install BAOMAIN 3 - fridge/receptacle AC source switch's jumpers (terminal 2-to-4, 6-to-8), **14 AWG**.
25. BAOMAIN 3 - fridge/receptacle AC source switch common to the fridge and USB-charging receptacles, **14 AWG** (receptacle products: TBD).

27. BAOMAIN 2 - oven/cooktop AC source switch common to BAOMAIN 4 - oven/cooktop AC destination switch common, **12 AWG**. mount BAOMAIN 4 - oven/cooktop AC destination switch and install its jumpers, **12 AWG** — this switch has no source role; it interlocks oven and cooktop so they can never both be live (see the BAOMAIN section above).

## settings

- XS (victronconnect): lithium profile, absorption at or below 27.6V, input current limit about 60A (verify against the alternator rating; the shared feed is 6 AWG, which caps safe continuous draw around 55-65A regardless of the 100A fuse — do not raise the limit toward the fuse's full rating), engine-running detection on.
- cerbo: DVCC on. the SOK ships with its own battery-to-inverter CAN cable (about 2m/6.5ft) — plug it in, no separate cable to buy. set the CAN port's profile per the cerbo CAN wiring note above.
- multiplus: AC input limit 30A on shore, about 14A on the honda, **16A on a household outlet** (a 20A residential circuit, common for home charging). the household number is deliberately different from the other two — a shore cord and the honda are both rated for continuous full-nameplate draw, but an ordinary household branch circuit isn't; NEC limits continuous loads to 80% of the breaker rating, so 20A × 0.8 = 16A. it does not follow BAOMAIN 1 - shore AC destination switch, so change it when the source changes. **battery type must be changed from the factory default** (victron gel/AGM, absorption 28.8V, float 27.6V for a 24V model) **to a lithium profile matching the SOK, absorption at or below 27.6V**. the SOK's own spec is 28V charge / 27.6V float, so this build runs it slightly conservative on purpose, not as a safety fix. per the cerbo manual, once DVCC and the CAN link to a *supported* battery are working, configuring charge voltage in VictronConnect "is unnecessary and has no effect" — the multiplus and XS charge using whatever voltage the battery's BMS sends over CAN. that's stronger than a fallback, but it hinges on the SOK being on victron's compatibility list (not yet confirmed) — set the local profile correctly regardless, in case that link isn't there. ground relay: on (default) — per victron's manual, this "automatically connects the Neutral output to the chassis if no external AC supply is available. If an external AC supply is provided, the ground relay will open before the input safety relay closes" — sequenced specifically so an earth-leakage breaker (the 8027's GFCI) always sees exactly one neutral-ground bond, never zero or two. matches this build's "no neutral-ground bond in any panel" decision — the multiplus is where that one bond actually lives, and it moves automatically depending on the source.

## limits and failure modes

- crimps and torque: a cheap crimper is the top cause of failed 2/0 lugs. torque values: egis busbar studs 120-140 in-lb; class T block (5502) 190 in-lb max; 7210 terminals 14 in-lb; 7210 mounting screws 6 in-lb; multiplus AC-in/AC-out terminals 2 Nm (screw terminal block, no lug — labeled N/PE/L); BAOMAIN terminals 1.2 N·m (M4 screw, no lug — max 6.0mm²/10 AWG).
- multiplus AC-in wire gauge: victron's own chart calls for 6 AWG minimum on this 3kVA model's AC-in and AC-out-1 (rated 50A, recommended 50A fuse/breaker). this build uses 10 AWG instead, which is correct specifically because the whole AC-in path is deliberately capped at 30A by the conntek inlet and the 8077 main — well under the port's 50A rating. if the multiplus's AC input current limit setting is ever raised above 30A, this reasoning no longer holds and the wire would need to be upsized. blue sea's own instructions independently recommend 10 AWG feeders for 30A systems (6 AWG for 50A) — matches this build's choice throughout the AC-in path.
- 8027 backlight: the panel's backlit labels are a DC device, not AC — needs their own fused (1.0-2.0A) DC feed and ground, separate from anything in the AC schedule. not yet routed to a source; voltage compatibility (12V vs 24V) isn't stated in blue sea's instructions — verify before wiring.
- 8027 neutral/ground bond: confirmed via blue sea's own wiring diagram that the neutral bus and ground bus are physically separate inside the panel — matches this build's "no neutral-ground bond in any panel" decision, no longer just an assumption.
- multiplus exterior grounding point: a separate wire from both its 2/0 DC negative connection and the AC ground wire that runs through it — victron's manual requires this as its own ≥4mm² conductor, "for safety purposes," independent of the ground relay's neutral-bonding function. it lands on the same - bar as every other negative/ground return in the system, which still makes only one wire (4 AWG) to actual chassis — this is a fifth wire feeding the existing single-point bond, not a second bond. was missing from the plan entirely until now.
- fuse order: the class T fuse goes in last.
- cerbo powering: only from the "Power in V+" terminal (8-70VDC), off the battery/busbar — never from a multiplus AC-out. victron's own manual warns this can deadlock the system after a fault or black start: the multiplus won't restart without the cerbo powered, and the cerbo won't power up without the multiplus's AC-out live.
- alternator load: the XS can pull over 100A from the 12V side at full output. set the input limit.
- XS fuse recommendation: victron's own manual calls for a dedicated 60-70A external fuse on the XS's input, paired with 6 AWG (under 5m) or 4 AWG (5-10m) — which is exactly what this build already uses for those gauges. but the actual fuse on this run is the shared 100A AEP unit at the battery, not a dedicated 60-70A one, because it's shared with the DJI charger. the XS's own software input limit (~60A) is what actually keeps normal operation inside the recommended range; a fault large enough to exceed 70A but under 100A would not be caught by the fuse the way victron's chart assumes. accepted tradeoff of the shared-feed design — not a defect to fix blindly, but worth knowing.
- shared van feed: battery selector 1 (off-1-2, no both) means only the XS or the DJI charger draws from the shared feed at a time, never both. the feed is 6 AWG (confirmed marked on the wire) fused at 100A (AEP, 65VDC, included with the DJI charger). the wire is the real limit, not the fuse — 6 AWG is good for roughly 55-65A continuous, so keep the XS input limit there regardless of the 100A fuse rating.
- multiplus capacity: about 2,400W continuous. the velit no longer draws from the multiplus's AC-out on its battery leg (2026-09-21 redesign, below), so it drops out of this check for that leg. water heater watts still TBD.
- kitchen redesign (2026-10-02): real nameplate watts — oven (typhur CV03) 1750W, 120VAC/60Hz (reference/Typhur_CV03SyncOven.pdf); cooktop (empava EMPV-12EC07) 1800W total, 120VAC/60Hz, and critically **"Minimum circuit breaker Amperage: 20"** printed in its own spec table (reference/EMPV-12EC07_Manual.pdf) — not just a sizing choice, a manufacturer requirement; fridge (deaprull D31A) 35-45W running, dual-voltage (AC 120/240V or DC 12/24V per its own product listings and an independent review — a spec-sheet screenshot that said 12VDC-only and "0.4 kWh annual" was wrong/misleading, not used). oven + cooktop combined (3550W/~29.6A) exceed every AC source in this build (shore/8077's 30A main has ~zero margin at that load, the honda's 1800W is blown past outright, the multiplus's 2400W continuous is exceeded by ~50% off-grid; DJI's AC output, confirmed 2026-10-02 at 4 ports/100-120V/25A ≈ 3000W continuous for the US variant per dji.com/power-2000/specs, is the closest of any source but still falls short of 3550W combined) — they can never safely share one branch or run together.
- kitchen circuit split (2026-10-02): two independent circuits instead of one shared "kitchen" branch. **15A circuit** (fridge + a USB charging outlet, assumed 120VAC — not yet confirmed as opposed to a 12V DC adapter) via BAOMAIN 3 - fridge/receptacle AC source switch, reusing the 8027's existing 15A branch. **20A circuit** (oven and cooktop) via BAOMAIN 2 - oven/cooktop AC source switch (source-select, DJI/victron) feeding BAOMAIN 4 - oven/cooktop AC destination switch (new switch, load-select between oven and cooktop — see the BAOMAIN section above), using a new breaker from one of the 8027's open positions. BAOMAIN 4 - oven/cooktop AC destination switch's mechanical interlock means oven and cooktop are never live together, so the 20A circuit never sees more than ~1800W (cooktop alone) — worst-case combined system draw (fridge+USB+one cooking appliance) is about 1905W/15.9A, which fits comfortably under shore power and the multiplus's off-grid rating, and only marginally over the honda's 1800W (by ~105W, a small overage compared to the ~1795W overage of the un-interlocked design).
- DJI AC output ports: confirmed via DJI's own manual (reference/DJI_Power_2000_um_en.pdf, section 1.1) to be physical plug-in outlets ("AC Output Ports," item 3 in the port diagram), not hardwired terminals — same category as a household outlet, not a screw terminal block. this is how the two DJI-leg taps for BAOMAIN 3 - fridge/receptacle AC source switch and BAOMAIN 2 - oven/cooktop AC source switch connect: a cord plugs into a DJI output port, its open end lands on the BAOMAIN terminal.
- kitchen appliance receptacles: the fridge, the USB outlet, and the oven are plug-in appliances with their own supplied cords (matching the pattern already used for the DJI AC-input branch, where DJI plugs its own cord into a receptacle rather than being hardwired) — so BAOMAIN 3 - fridge/receptacle AC source switch's leg/common wiring and BAOMAIN 4 - oven/cooktop AC destination switch's oven leg terminate in receptacles, not bare appliance hardwiring. the cooktop is the exception, confirmed 2026-10-02: its own manual requires hardwiring by a qualified technician, no plug, so BAOMAIN 4 - oven/cooktop AC destination switch's cooktop leg wires directly to the cooktop's own leads instead. specific receptacle products (fridge, USB, oven): TBD.
- wire reassignment (2026-10-02): the 12 AWG 12/3 triplex marine wire (20ft, tinned OFC) that was slated for the BAOMAIN 1 - shore AC destination switch→3131→DJI-receptacle (AC input/charging) branch is reassigned to the new 20A oven/cooktop circuit instead — 12 AWG is the NEC minimum for 20A anyway, so the gauge still fits its new job. **the AC input/charging branch now has no wire assigned** — still an open item, see verify.md. separately, two "iron forge" 12 AWG/3-conductor/15A-rated replacement-appliance cords (15ft and 6ft, molded 90° plug on one end, open end on the other) cover the two new DJI-output-port taps instead — the molded plug end stays intact and plugs into one of DJI's two AC output ports; the open end wires to BAOMAIN 3 - fridge/receptacle AC source switch's or BAOMAIN 2 - oven/cooktop AC source switch's position-1 terminal. which cord goes where (15ft vs 6ft) just depends on which BAOMAIN ends up physically closer to the DJI unit.
- velit redesign (2026-09-21): the velit now runs on **battery selector 2**, not BAOMAIN 2 - oven/cooktop AC source switch — position 1 is the DJI-fed meanwell (unchanged from before), position 2 taps the 24V bus directly (no inverter/meanwell round trip). this recovers the multiplus-inverter (94% max) → meanwell (88% typ) round-trip loss (about 17%, from their own datasheets — reference/32424-MultiPlus-II___Quattro-II-pdf-en.pdf p.26, reference/RSP-1000-SPEC.pdf p.2) whenever the velit runs on battery power. it does not change anything about the DJI leg, which still goes through the meanwell exactly as before — the "meanwell required on the DJI leg" reasoning from the original design (the "24" in "multiplus-ii 24/3000/70" is the DC battery-side voltage; AC-out-1 is always 120V AC; the velit needs 24V DC) still applies there, it's just no longer required on the victron leg. BAOMAIN 2 - oven/cooktop AC source switch is now spare; its 8027 branch is free for another circuit (candidate: the water heater, still TBD).
- DC switching under load: selector 2 is a mechanical battery-disconnect switch, not rated for breaking load current. switch it only with the velit powered off, same caution that applies to selector 1 and the AEP fuse pull in phase 3.
- DJI limits: AC input max 15A (about 1,800W, equal to the honda's rated output). the SDC-to-XT60 cable feeding the 5026 bus is 13.6V default / 10A max per DJI's own spec (corrected from an earlier "12A per port" figure) — that cable, not the fuse on it, is the real ceiling on the 12V bus. fixed: was a 40A ANL, now a 10-15A ATC/ATO inline fuse — see the schedule.
- 5026 fuse block: blue sea's own spec caps the upstream feed fuse at 125A max, well above what this build uses. their wiring diagram explicitly says to consult ABYC E-11 Table V to size that fuse's *interrupt rating* to the source's short-circuit capacity, not just its trip current — not yet checked (see verify.md). mounts with #8 or M4 screws, 2.5in hole spacing; terminal screws are #8-32. reference/5026.pdf, reference/Wiring-Diagram-5026_5031.pdf
- DJI AC output auto-behavior: shuts off after 30 minutes with no load drawing, and shuts down entirely after 60 minutes with no input or output. the fridge (now sharing BAOMAIN 3 - fridge/receptacle AC source switch's 15A circuit with the USB outlet, 2026-10-02) cycles on and off, so between compressor cycles the DJI may see "no load" and cut power — the AC button needs to be held for continuous-supply mode whenever this circuit runs off the DJI leg, or the fridge loses power between cycles. doesn't apply to the oven/cooktop circuit (BAOMAIN 2 - oven/cooktop AC source switch / BAOMAIN 4 - oven/cooktop AC destination switch), which isn't expected to idle for 30+ minutes while live.
- cam switches: AC only, Ith 32A confirmed on the actual unit's nameplate. turn loads off before switching.
- SOK cold: the heater only works while a charge source is present.
- housings: the 8077 and 8027 mount with 4 screws directly to a flat surface (per their own install template) — not into a recessed cutout window. everything behind the face (breakers, buses, wiring) is exposed unless boxed in. blue sea sells no surface-mount enclosure for this panel family — their "SMS Surface Mount System" line looks similar but is a separate, incompatible product built around different (Carling A/C-series) breakers. the plan for both panels: a generic IP65+ ABS or polycarbonate enclosure box, non-metallic (a metal box would need deliberate bonding, which conflicts with this build's single-chassis-bond design), front face at or slightly larger than the panel footprint (5-1/4 x 7-1/2in for the 8027; check the 8077's own dimensions) so the panel's own face plate seals the opening, at least 3in internal depth (matches blue sea's 4026 back cover rating), blank walls for drilling/glanding cable entry. this is standard practice among other van builders using these same panels — see verify.md. keep the inlet-to-8077 run short.
- 3131 box: you drill the gland holes (1-1/8"). try the glands on your cable first.
- DJI super fast charger: not water or dust resistant, needs a protected mounting spot. wire and secure the charger's own cables first, then connect the fuse and battery cables, to avoid a short. default charging power is 500W; raise to 1000W in the DJI app once installed.
- selector 2 to velit: uses the velit's own 6 AWG power cable, not a separately bought wire. that cable has fuse boxes on both positive and negative at the velit end, and one fuse box on positive only at the source end — the source end is now selector 2's OUTPUT terminal, not the meanwell directly (2026-09-21). sized for the 12V variant's 60A; comfortably covers the 24V variant's 10-33A actually installed.
- meanwell RSP-1000-24: draws up to 12A at 115VAC full load (960W), with 25A inrush — informs the DJI-out-to-meanwell branch gauge (14 AWG comfortably covers 12A, matching this build's other 15A-class branches). **confirmed 2026-10-03**: no separate breaker needed on this branch — it's a cord plugging into one of DJI's AC output ports (same as the kitchen taps), relying on DJI's own output protection and the meanwell's own internal AC-input protection, not a dedicated external breaker. ships with remote-on/off pins shorted by default, so it just runs whenever AC is present. output is adjustable 20-26.4V — the 24V setpoint for the velit is within that range with headroom either direction. as of the 2026-09-21 redesign it only ever serves the DJI leg, and its DC output negative is permanently bonded to the system's negative bar (see the battery-selectors note above).
